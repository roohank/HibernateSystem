HibernateSystem

An NVDA add-on that hibernates the Windows system with a single keyboard shortcut.

Keyboard Shortcut

  • NVDA + Alt + H: Hibernate the system

Requirements

For this add-on to work, the Hibernate feature must be enabled in Windows. Run powercfg /hibernate on as administrator to enable it.
